COLOR TRIP

계정 및 데이터 삭제 요청

앱: Color Trip - 여행 지도 색칠 · 개발자: DGSTUDIO

Color Trip에 저장된 데이터는 언제든 삭제할 수 있습니다. 앱 안에서 직접 지우는 방법과, 서버에 남은 데이터까지 한 번에 삭제 요청하는 방법을 안내합니다.

1. 앱에서 직접 지우기

  • 칠한 지역 — 지역을 누른 뒤 색을 지우면 기록이 삭제됩니다.
  • 메모 — 메모 옆 ⋯ 버튼을 눌러 ‘메모 삭제’를 고르면 삭제됩니다.
  • 계정과 모든 데이터 — 앱 오른쪽 위 사람 모양 버튼 → 맨 아래 ‘내 데이터 삭제’를 누르면 아래 3번의 데이터와 익명 계정이 즉시 삭제됩니다.
  • 휴대전화 안의 사진 기록 — ‘내 데이터 삭제’를 하거나 앱을 삭제하면 함께 지워집니다.

2. 메일로 삭제 요청하기

앱을 이미 지워 앱에서 삭제할 수 없다면 아래 순서로 요청해 주세요.

  • 1단계 — 쓰던 닉네임과 참여했던 지도 이름을 준비합니다. 회원가입이 없는 익명 계정이라 이 정보로 계정을 찾습니다.
  • 2단계 — geunsoo7@gmail.com 으로 제목을 “Color Trip 계정 삭제 요청” 으로 하여 메일을 보냅니다. 본문에 1단계의 닉네임과 지도 이름을 적어 주세요.
  • 3단계 — 접수 후 영업일 기준 7일 이내에 삭제하고 회신해 드립니다.

3. 삭제되는 데이터

  • 익명 계정 식별자와 닉네임
  • 내가 만든 지도, 지도 이름, 초대 코드, 참여자 정보
  • 내가 칠한 지역 기록(지역 코드 · 색 · 시각)
  • 내가 작성한 메모 (다른 사람 지도에 남긴 메모 포함)
  • 차단 목록 · 이용 규칙 동의 기록
  • 이 기기에 저장한 사진 기록 (앱에서 삭제한 경우)

4. 보관되는 데이터

  • 없음. 위 데이터는 요청 즉시 영구 삭제되며 백업본도 남기지 않습니다. 법령상 보관 의무가 있는 정보는 수집하지 않습니다.
  • 다만 다른 사람이 만든 지도에 칠한 색은 그 지도를 함께 쓰는 사람들의 기록이라 남습니다. 메일로 요청하시면 본인이 칠한 기록만 골라 삭제합니다.
  • 내가 남긴 신고 기록은 신고 처리가 끝나면 삭제합니다.
  • 사진은 서버에 저장하지 않으므로 삭제할 서버 데이터가 없습니다. 휴대전화 안의 사진은 앱을 지우면 함께 삭제됩니다.
